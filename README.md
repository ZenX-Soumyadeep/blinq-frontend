# BlinQ Frontend 🎬

A modern, full-stack Letterboxd clone built for movie tracking, community reviews, and role-based moderation. 

## 🚀 Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS v4
- **External API:** TMDB (The Movie Database)
- **Icons:** Lucide React

## ✨ Features
- **Live Trending Movies:** Fetches real-time movie data and posters via the TMDB API.
- **Interactive Review System:** Users can rate (1-5 stars) and log reviews tied specifically to TMDB Movie IDs.
- **Role-Based UI:** Dynamic navigation and moderation tools (e.g., delete buttons) visible only to Admin accounts.
- **Authentication State:** Client-side session management communicating with the Spring Boot API.
